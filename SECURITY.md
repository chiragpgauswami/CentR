# Security Policy

## Supported Versions

Currently, only the latest release of CentR is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report security issues responsibly. Do NOT create public issues for security vulnerabilities.
Instead, send an email to the repository maintainers or use GitHub's private vulnerability reporting feature.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We aim to resolve vulnerabilities within 30 days of the report.
- We will provide updates every 7 days until resolution.
