# Contributing to CentR

Thank you for your interest in contributing to CentR!

## Development Setup

1. Fork and clone the repository.
2. Ensure you have Node.js 20+ installed.
3. Install dependencies: `npm install`
4. Build the project: `npm run build`
5. Run tests: `npm test`

## Pull Request Process

1. Create a descriptive branch name (e.g., `feat/add-indexer-memory`).
2. Implement your feature or bugfix, ensuring you include tests.
3. Run `npm run typecheck` and `npm run lint` before submitting.
4. Open a pull request against the `main` branch.
5. Provide a clear description of the problem solved and links to relevant issues.

## Code Style

- Use TypeScript with strict mode.
- Format code using Prettier (`npm run format`).
- Ensure no ESLint errors or warnings.
- Keep functions pure and document complex logic.

We look forward to your contributions!
