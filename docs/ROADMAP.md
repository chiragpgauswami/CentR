# CentR Roadmap

## V0.1 (Current)
- Core indexing, search, context, memory, learning.
- CLI implementation.
- MCP (Model Context Protocol) integration.

## V0.2
- Tree-sitter integration for robust AST parsing.
- More languages support (Python, Go, Rust).
- Semantic search improvements (local embeddings).

## V0.3
- Local LLM integration for 100% offline functionality.
- Automated learning extraction from agent actions.

## V1.0
- Plugin system for custom parsers, skills, or storage backends.
- Community skills registry.
- Cross-project learning sync for teams.
